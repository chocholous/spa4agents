## Change: simplification (owner decision, 31 October 2026)

S1. **Rejecting secrets and PII before processing is dropped** (data policy principle, `docs/zadani.md`, plan, `gateway/NOTES.md`, web/data-policy text). Zero retention of everything else is unchanged. The locked schema keys (`recovery_inputs_days`, `checkpoint_stored`) are untouched and refer to no secrets/PII rule. S2. **Trial = all paid tools.** `trial.covered: all_paid`; 3 sessions of 20 turns remain changeable defaults. Open: "turn" is still undefined (gateway question 5), `trial.valid_days` is now 14 (owner, 31 Oct 2026), and the anti-farm and guest-pass fields are kept as they were (candidates for removal, see the report).
S3. **Free vs paid.** Free: all `lobby.*` (`lobby.checkin`, `lobby.find_tool`, `lobby.concierge`, `lobby.leave`, `lobby.balance`, `lobby.referral_code`, `lobby.redeem`), `quiet.pause`, `quiet.end_session_hint`. No amounts invented: paid tools stay "Pricing being finalized".
S4. **Free `lobby.concierge` is an LLM call nobody pays for: abuse risk.** Anyone can call it without a payment, so it can be used to burn LLM budget (and a prompt-injection or relay vector). Recommendation (owner decides): a configurable cap, for example N calls per session and M per address and day (suggested start: 3 per session, 20 per address per day, settable in the catalog/env, nothing is hardcoded), a short max input length, a small and cheap model, and a global daily budget that makes the tool return "try later" when spent. S5. **F2/F3 tools and the trial.** The trial now covers them too, once they exist. For stateful or publishing tools (`lounge.bar`, `chapel.reflect_private` with `public`) a free trial is a spam vector that the removed exclusion used to prevent. Decide whether to reintroduce it.
